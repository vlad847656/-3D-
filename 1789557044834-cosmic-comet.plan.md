# Minecraft-like Game Implementation Plan

## Overview
Simple Minecraft-like game using **Java2D with isometric (2.5D) rendering**. Zero external dependencies — pure JDK.

## Package Structure
```
src/
├── Main.java                          -- Entry point, JFrame, game loop
├── game/
│   ├── Game.java                      -- Core game state manager
│   ├── GameScreen.java                -- JPanel: rendering + input
│   └── GameState.java                 -- Enum: MENU, PLAYING, PAUSED, GAME_OVER
├── world/
│   ├── World.java                     -- Chunk/terrain management
│   ├── Chunk.java                     -- 3D block array per chunk (16x64x16)
│   ├── BlockType.java                 -- Enum: AIR, GRASS, DIRT, STONE, WOOD, LEAVES, SAND, WATER, PLANKS, COBBLESTONE
│   ├── Block.java                     -- Block type + position
│   ├── TerrainGenerator.java          -- Noise-based terrain + trees + water
│   └── ChunkManager.java             -- Multi-chunk management
├── player/
│   ├── Player.java                    -- Position, velocity, health, inventory
│   ├── Inventory.java                 -- 36-slot inventory + 9-slot hotbar
│   ├── Hotbar.java                    -- Hotbar rendering
│   └── PlayerInput.java               -- WASD + mouse input
├── rendering/
│   ├── Renderer.java                  -- Rendering orchestration
│   ├── IsometricRenderer.java         -- Isometric projection + block drawing
│   ├── Camera.java                    -- Camera following player
│   └── ParticleSystem.java            -- Block break/place particles
├── entities/
│   ├── Entity.java                    -- Base entity class
│   ├── Monster.java                   -- Enemy with AI
│   ├── MonsterType.java               -- ZOMBIE, SKELETON, SPIDER
│   └── MonsterSpawner.java            -- Spawn monsters at night
├── systems/
│   ├── HealthSystem.java              -- Player health + hearts rendering
│   └── DayNightCycle.java             -- Time cycle + lighting
└── assets/
    └── AssetRegistry.java             -- Block face colors (top/left/right)
```

## Implementation Steps

### Step 1: Project Setup — JFrame + Game Loop
- `GameState.java` — enum (MENU, PLAYING, PAUSED, GAME_OVER)
- `GameScreen.java` — extends JPanel, BufferStrategy, KeyListener, MouseListener
- `Game.java` — game loop with fixed timestep (System.nanoTime delta)
- `Main.java` — creates 1280x720 JFrame, adds GameScreen

**Verify:** Black window opens and stays open.

### Step 2: Block Types + Asset Colors
- `BlockType.java` — enum with color, hardness, solidity
- `AssetRegistry.java` — top/left/right face colors per block

**Verify:** All block types compile and print correctly.

### Step 3: Chunk & Block Data Model
- `Block.java` — record(type, x, y, z)
- `Chunk.java` — Block[16][64][16] grid
- `ChunkManager.java` — Map<Point, Chunk>, world coordinate lookup

**Verify:** Create 4x4 chunks, fill with stone, print coordinates.

### Step 4: Terrain Generation
- `TerrainGenerator.java` — sine-combination noise, heightmap 20-40
- Grass on top, dirt below, stone deeper, trees at 2% chance, water below y=18

**Verify:** Cross-section shows correct layering + trees.

### Step 5: Isometric Rendering Engine
- `Camera.java` — follows player, world-to-screen projection
- `IsometricRenderer.java` — draws diamond faces (top/left/right)
- `Renderer.java` — renders blocks, player, monsters, UI, day/night overlay

**Verify:** Isometric world with terrain, trees, player visible. Camera follows.

### Step 6: Player Movement + Input
- `Player.java` — position, velocity, gravity, collision, jumping
- `PlayerInput.java` — WASD (isometric directions), SPACE jump, 1-9 hotbar

**Verify:** WASD moves player, camera follows, SPACE jumps, no falling through world.

### Step 7: Block Breaking + Placing
- Left click = break block (adds to inventory)
- Right click = place block (from hotbar)
- Inverse isometric projection for screen-to-world

**Verify:** Break/place works, hotbar count updates.

### Step 8: Inventory + Hotbar
- `Inventory.java` — 36 slots, add drops, remove from slot
- `Hotbar.java` — renders 9 slots at bottom, white border on selected

**Verify:** Break blocks → appear in hotbar. Place → count decreases.

### Step 9: Monsters + AI
- `MonsterType.java` — ZOMBIE(20hp), SKELETON(16hp), SPIDER(12hp)
- `Monster.java` — moves toward player, gravity, collision
- `MonsterSpawner.java` — spawns at night at chunk edges

**Verify:** Monsters spawn at night, move toward player, die when hit.

### Step 10: Health System
- `HealthSystem.java` — 20 HP, hearts rendering (full/half/empty)
- Monster contact = 1 damage per 2 seconds
- 0 HP = GAME_OVER state

**Verify:** Hearts display correctly, health decreases on contact, game over at 0.

### Step 11: Day/Night Cycle
- `DayNightCycle.java` — 600s full cycle, brightness 0.2-1.0
- Blue overlay at night, monsters spawn only at night
- Daytime = monsters take burn damage

**Verify:** Screen darkens/lightens, monsters spawn at night, burn during day.

### Step 12: Particles + Polish
- `ParticleSystem.java` — colored particles on block break
- Gravity + fade-out

**Verify:** Block breaking shows particle effects.

### Step 13: Menu + Game Over Screens
- `GameScreen.java` — MENU (Enter to start), PAUSED (Escape), GAME_OVER
- Controls displayed on menu

**Verify:** Menu shows, Enter starts, Escape pauses, Game Over at 0 HP.

## Dependencies
**None.** Pure JDK: javax.swing, java.awt, java.util, java.awt.event.
