# 🎮 Minecraft 3D (Java) — FPS версия

Полноценный аналог Minecraft от **первого лица** на чистом Java (Java2D + 3D-рендеринг с перспективой).

## 🚀 Запуск

### Способ 1: Двойной клик по `run.bat`
### Способ 2: Через консоль
```powershell
cd C:\Users\vlad2\IdeaProjects\Games-play
.\run.bat
```

### Способ 3: Ручная компиляция и запуск
```powershell
javac -d out src/Main.java src/game/*.java src/world/*.java src/player/*.java src/rendering/*.java src/entities/*.java src/systems/*.java src/assets/*.java
java -cp out Main
```

## 🎮 Управление

| Клавиша | Действие |
|---------|----------|
| **W A S D** | Движение (вперёд/назад/влево/вправо) |
| **SPACE** | Прыжок |
| **Мышь** | Обзор (поворот камеры) |
| **ЛКМ** | Сломать блок / Атаковать монстра |
| **ПКМ** | Поставить блок |
| **1-9** | Выбор слота в хотбаре |
| **ESC** | Пауза (освобождает мышь) |
| **ENTER** | Начать игру / Рестарт |

> 💡 **Важно:** При старте игры кликните в окно, чтобы захватить мышь. ESC освобождает курсор.

## 🎯 Особенности игры

### 🌍 Мир
- **Полноценное 3D от первого лица** с перспективной проекцией
- **Процедурная генерация** ландшафта с холмами, деревьями и водоёмами
- Разнообразные блоки: трава, земля, камень, дерево, листва, песок, вода, доски, булыжник, бедрок
- Небо с солнцем и облаками
- Цикл дня и ночи с изменением освещения

### ⛏️ Геймплей
- **Ломать блоки** — левый клик мыши
- **Ставить блоки** — правый клик мыши
- **Инвентарь** — 36 слотов, 9 слотов хотбара
- **Подбор ресурсов** — автоматически при разрушении блока

### 👾 Монстры
- **Зомби** (зелёный) — 20 HP, медленный, сильный
- **Скелет** (белый) — 16 HP, средний
- **Паук** (фиолетовый) — 12 HP, быстрый

### 🐄 Животные
- **Корова** (коричневая) — 10 HP, дроп: кожа, сырое мясо
- **Свинья** (розовая) — 8 HP, дроп: сырая свинина
- **Курица** (белая) — 4 HP, дроп: перо, сырая курица
- **Овца** (бежевая) — 6 HP, дроп: шерсть

Животные мирные, бродят по миру. Можно убить ЛКМ для получения ресурсов!

### 🌙 Цикл дня и ночи
- Длительность цикла: 5 минут
- **Ночью** спавнятся монстры
- **Днём** монстры получают урон от солнца
- Тёмный оверлей ночью

### ❤️ Здоровье
- 20 HP (10 сердец)
- Монстры наносят урон при контакте
- При 0 HP — Game Over

## 📁 Структура проекта

```
src/
├── Main.java                          # Точка входа
├── game/
│   ├── Game.java                      # Менеджер игры
│   ├── GameScreen.java                # Окно + ввод + игровой цикл
│   └── GameState.java                 # Состояния: MENU, PLAYING, PAUSED, GAME_OVER
├── world/
│   ├── Block.java                     # Блок (тип + координаты)
│   ├── BlockType.java                 # Типы блоков
│   ├── Chunk.java                     # Чанк 16x64x16
│   ├── ChunkManager.java              # Управление чанками
│   ├── World.java                     # Мировое управление
│   └── TerrainGenerator.java          # Генерация ландшафта
├── player/
│   ├── Player.java                    # Игрок (позиция, здоровье, физика)
│   ├── Inventory.java                 # Инвентарь 36 слотов
│   └── Hotbar.java                    # Хотбар 9 слотов
├── rendering/
│   ├── Camera.java                    # Камера
│   ├── IsometricRenderer.java         # Изометрическая отрисовка
│   ├── Renderer.java                  # Главный рендерер
│   └── ParticleSystem.java            # Частицы при разрушении блоков
├── entities/
│   ├── Entity.java                    # Базовый класс сущности
│   ├── Monster.java                   # Монстр с ИИ
│   ├── MonsterType.java               # Типы монстров
│   └── MonsterSpawner.java            # Спавн монстров
├── systems/
│   ├── HealthSystem.java              # Здоровье игрока
│   └── DayNightCycle.java             # Цикл дня/ночи
└── assets/
    └── AssetRegistry.java             # Цвета блоков
```

## 🛠️ Технологии
- **Java 21**
- **Java2D** (без внешних библиотек!)
- **Izometric rendering** для 3D-эффекта
- **BufferStrategy** для плавного рендеринга
- **Fixed timestep** игровой цикл

## 📝 Лицензия
Бесплатно для личного использования.
